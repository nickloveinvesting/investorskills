The mechanism

A prompt asks. A skill decides.

Same model, same deal, two different objects. One is a message you retype. The other is a workflow the model has to obey.

A prompt

  • Pasted fresh each time, worded slightly differently
  • Answers whatever it is given, including nothing
  • Hides which assumptions it invented
  • Same deal, two sessions, two verdicts
  • No record of what it refused to consider

A skill

  • Installed once, applies to every conversation
  • Declares required inputs and stops without them
  • Prints every default it used, so you can override it
  • Fixed decision thresholds, so the verdict repeats
  • Names the one input the deal is most sensitive to
