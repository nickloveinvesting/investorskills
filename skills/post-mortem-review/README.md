# Deal Post-Mortem Review

Run the honest review after a deal closes so the same mistake does not cost you twice.

- **Category:** Business Systems & Numbers
- **Price:** Free
- **Built for:** Fix-and-Flipper, Wholesaler

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/post-mortem-review/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
