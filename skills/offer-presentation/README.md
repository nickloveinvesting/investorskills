# Low Offer Presentation Framework

Present a number well below asking in a way that gets a counter instead of a hang-up.

- **Category:** Seller Outreach & Negotiation
- **Price:** $27
- **Built for:** Wholesaler, Fix-and-Flipper

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/offer-presentation/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
