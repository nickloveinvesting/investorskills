# Due Diligence Period Runner

Work a 30-45 day DD period in the order that surfaces deal-killers before your money goes hard.

- **Category:** Contracts & Transaction Ops
- **Price:** $27
- **Built for:** Small Multifamily Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/due-diligence-checklist/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
