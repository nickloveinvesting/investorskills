# Short-Term Rental Feasibility Check

Pressure-test an STR pro forma against regulation risk, seasonality, and realistic occupancy before you furnish anything.

- **Category:** Deal Analysis & Underwriting
- **Price:** $27
- **Built for:** First-Deal Investor, Fix-and-Flipper

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/str-feasibility/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
