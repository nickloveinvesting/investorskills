# 60-Second Deal Screener

Kill bad deals in under a minute so you spend your day on the three that can actually close.

- **Category:** Deal Analysis & Underwriting
- **Price:** Free
- **Built for:** Wholesaler, First-Deal Investor

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/deal-screener-triage/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
