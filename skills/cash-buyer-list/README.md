# Cash Buyer List Builder

Build a buyer list from actual closed-transaction data instead of collecting business cards at meetups.

- **Category:** Disposition & Buyer Management
- **Price:** $27
- **Built for:** Wholesaler

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/cash-buyer-list/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
