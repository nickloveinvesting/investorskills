# Loan Product Matcher

Match the deal to the right loan product before you waste three weeks with the wrong lender.

- **Category:** Funding & Capital Raise
- **Price:** Free
- **Built for:** First-Deal Investor, Fix-and-Flipper

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/dscr-lender-matcher/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
