# Seller Call Script System

Run a first seller call that surfaces motivation and condition without triggering the defensive wall a pitch creates.

- **Category:** Seller Outreach & Negotiation
- **Price:** $27
- **Built for:** Wholesaler, First-Deal Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/seller-call-script/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
