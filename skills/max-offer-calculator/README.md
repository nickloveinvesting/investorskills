# Max Allowable Offer Builder

Get a walk-away number backed by real spread math instead of a 70% rule you cannot defend to a seller.

- **Category:** Deal Analysis & Underwriting
- **Price:** Free
- **Built for:** Wholesaler, Fix-and-Flipper, First-Deal Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/max-offer-calculator/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
