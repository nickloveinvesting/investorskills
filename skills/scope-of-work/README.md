# Scope of Work Generator

Turn a walkthrough into a line-item scope contractors can bid apples-to-apples against.

- **Category:** Rehab Scoping & Contractors
- **Price:** $27
- **Built for:** Fix-and-Flipper, Small Multifamily Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/scope-of-work/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
