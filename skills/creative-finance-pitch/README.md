# Creative Finance Pitch Builder

Structure and explain seller financing or subject-to in terms a non-investor seller will actually agree to.

- **Category:** Seller Outreach & Negotiation
- **Price:** $27
- **Built for:** Small Multifamily Investor, First-Deal Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/creative-finance-pitch/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
