# Buyer Pushback Handler

Hold your number when a cash buyer tries to retrade you two days before closing.

- **Category:** Disposition & Buyer Management
- **Price:** Free

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/buyer-objection-dispo/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
