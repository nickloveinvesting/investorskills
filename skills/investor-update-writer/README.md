# Investor Update Writer

Send the quarterly update that keeps capital coming back, including how to report a bad quarter.

- **Category:** Funding & Capital Raise
- **Price:** $27
- **Built for:** Small Multifamily Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/investor-update-writer/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
