# Rehab Cost Estimator

Price a rehab from photos and a square footage number, with the contingency sized to the age of the building.

- **Category:** Rehab Scoping & Contractors
- **Price:** $27
- **Built for:** Fix-and-Flipper, Wholesaler

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/rehab-cost-estimator/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
