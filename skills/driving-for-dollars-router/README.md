# Driving for Dollars Route Planner

Turn a target zip into a route and a scoring rubric so a two-hour drive produces a ranked list, not a phone full of photos.

- **Category:** Lead Generation & List Building
- **Price:** $27
- **Built for:** Wholesaler, First-Deal Investor

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/driving-for-dollars-router/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
