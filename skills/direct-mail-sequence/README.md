# Direct Mail Sequence Builder

Build a six-touch mail sequence where each piece says something different instead of shouting the same offer louder.

- **Category:** Lead Generation & List Building
- **Price:** $27
- **Built for:** Wholesaler

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/direct-mail-sequence/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
