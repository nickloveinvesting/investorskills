# Closing Timeline Manager

Run the contract-to-close calendar backwards from funding so no deadline gets discovered late.

- **Category:** Contracts & Transaction Ops
- **Price:** $27
- **Built for:** Wholesaler, Fix-and-Flipper

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/closing-timeline-manager/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
