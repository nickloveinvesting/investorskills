## 5-Year Pro Forma Construction

### Revenue Assumptions

#### Year 1 (Acquisition Year)
```
Gross Potential Rent = Current Rent Roll (annualized)
- Physical Vacancy: Actual in-place or 5% minimum
- Economic Vacancy: 2-3% (concessions, bad debt, loss-to-lease)
- Collection Loss: 1-2%
= Effective Gross Income

+ Other Income:
  - Late fees: $15-25/unit/year
  - Application fees: $35-50/application
  - Pet rent: $25-50/pet/month (if applicable)
  - Parking: $25-75/space/month (if applicable)
  - Laundry: $15-30/unit/year
  - Storage: $50-100/unit/month (if applicable)
```

#### Years 2-3 (Value-Add Execution)
```
Rent Growth Assumptions:
- Renovated units: Market rent upon turnover
- Unrenovated occupied: 3-5% annual increases
- Market rent growth: 1.5-3% annually (adjust for submarket)

Vacancy During Renovation:
- Budget 30-60 days vacancy per renovated unit
- Stagger renovations to minimize income loss
- Target 2-4 units/month renovation pace for 20-50 unit property

Other Income Growth:
- Implement RUBS: Add $30-80/unit/month (after 60-90 day implementation)
- Pet program: Add $25-50/pet/month
- Parking optimization: Add $25-75/space where applicable
```

#### Years 4-5 (Stabilized Operations)
```
Assumptions:
- Physical vacancy: 5-7%
- Rent growth: Market rate (2-3% annually)
- Expense growth: 2-3% annually
- CapEx reserves: $300-400/unit/year
- All units at market rent
```

### Expense Projections

#### Year 1 Expenses (Baseline)
Start with seller's T12, then adjust:
```
Adjustments to Make:
+ Property management (if currently self-managed): 8% of EGI
+ Property taxes (verify current assessment, check for reassessment risk)
+ Insurance (get your own quote, typically higher than seller's)
+ Deferred maintenance catch-up (one-time items)
- Owner perks being eliminated (personal expenses run through property)
- One-time items in T12 (legal fees, unusual repairs)
```

#### Years 2-5 Expense Growth
```
Category               Annual Growth
----------------------------------------
Property Taxes         2-4% (verify local trends)
Insurance             5-8% (market dependent)
Utilities             2-4%
Repairs & Maintenance  2-3% (declining after deferred maintenance addressed)
Property Management    Flat % of revenue
Administrative         2-3%
Contract Services      2-3%
Payroll (if applicable) 3-4%
```

## NOI Analysis and T12 Normalization

### T12 Normalization Checklist

#### Revenue Adjustments
```
1. Vacancy Adjustment
   - If current vacancy < 5%, use 5% minimum
   - If current vacancy > market, use actual and trend

2. Rent Adjustments
   - Remove one-time move-in specials
   - Annualize any mid-year rent increases
   - Adjust for known upcoming vacancies

3. Other Income Normalization
   - Remove extraordinary items (insurance claims, legal settlements)
   - Annualize items that started mid-year
   - Add back items seller stopped tracking (late fees, etc.)
```

#### Expense Adjustments
```
1. Property Management
   - Add 8-10% if currently self-managed
   - Verify fee structure (flat fee vs % of collections)

2. Property Taxes
   - Verify current assessment
   - Check for supplemental bills
   - Estimate reassessment upon sale (varies by jurisdiction)
   - DFW: Expect 80-100% of purchase price assessment

3. Insurance
   - Get your own quote (seller's coverage often inadequate)
   - Factor in age of property and claims history
   - Budget for increased coverage post-renovation

4. Repairs & Maintenance
   - Separate CapEx from R&M
   - Normalize for deferred maintenance being addressed
   - Use per-unit benchmarks as sanity check

5. Utilities
   - Identify what's owner-paid vs tenant-paid
   - Normalize for weather extremes
   - Factor in RUBS implementation plans

6. Remove Non-Operating Items
   - Mortgage payments (not an operating expense)
   - Owner draws
   - Depreciation
   - Income taxes
   - Capital expenditures
```

### NOI Quality Score

Rate each factor 1-5 (5 = best):

| Factor | Score | Notes |
|--------|-------|-------|
| Income documentation quality | | Rent roll matches deposits? |
| Expense documentation quality | | Invoices support T12? |
| Tenant quality (payment history) | | Collections issues? |
| Lease term remaining | | MTM heavy = risk + opportunity |
| Below-market rent opportunity | | Loss-to-lease amount |
| Expense reduction opportunity | | Above benchmark categories? |
| **Total NOI Quality Score** | **/30** | |

**Interpretation:**
- 25-30: High confidence in underwriting
- 18-24: Proceed with verification focus
- Below 18: Significant uncertainty, require additional due diligence


## DSCR Requirements by Lender Type

### Agency Loans (Fannie Mae / Freddie Mac)

```
Loan Parameters:
- DSCR Requirement: 1.20 - 1.25 minimum
- LTV: Up to 80% (75% more common for value-add)
- Term: 5, 7, 10, or 12 years
- Amortization: 30 years
- Rate Type: Fixed or floating
- Prepayment: Yield maintenance or defeasance

Best For:
- Stabilized properties (90%+ occupancy)
- 5+ units
- Good physical condition
- Strong sponsor

Typical Terms (2024-2025):
- Rate: 5.5-6.5% (market dependent)
- Minimum loan: $1 million (soft floor)
- Non-recourse available
```

### CMBS (Commercial Mortgage-Backed Securities)

```
Loan Parameters:
- DSCR Requirement: 1.25 - 1.30 minimum
- LTV: Up to 75%
- Term: 5 or 10 years
- Amortization: 30 years
- Rate Type: Fixed
- Prepayment: Yield maintenance or defeasance

Best For:
- Larger deals ($2M+)
- Stabilized properties
- Longer hold periods
- Non-recourse preference

Considerations:
- Less flexibility during term
- Reserves often required
- Assumption fees high
```

### Bridge / Hard Money Loans

```
Loan Parameters:
- DSCR Requirement: 1.10 - 1.15 (or interest-only)
- LTV: Up to 75-80% of as-is value
- LTC: Up to 85-90% of total project cost
- Term: 12-36 months
- Rate Type: Floating (SOFR + spread)
- Prepayment: Typically 1-2% for first 12 months

Best For:
- Value-add acquisitions
- Properties needing lease-up
- Quick closings required
- Repositioning plays

Typical Terms (2024-2025):
- Rate: 8-12% (credit and property dependent)
- Extension options: 6-12 months
- Recourse required (usually)
- Interest reserves common
```

### Local/Regional Bank Loans

```
Loan Parameters:
- DSCR Requirement: 1.25 - 1.35 minimum
- LTV: Up to 75%
- Term: 5-7 years (some up to 10)
- Amortization: 20-25 years
- Rate Type: Fixed or floating
- Prepayment: Varies (often flexible)

Best For:
- Relationship borrowers
- Smaller deals ($500K-$3M)
- Local properties
- Flexible terms needed

Advantages:
- More negotiable terms
- Personal relationship matters
- Faster decisions sometimes
- Portfolio lenders can be creative
```

### DSCR Calculation Example

```
Property: 25 units, $3.5M purchase price

NOI (Year 1 Stabilized): $245,000

Loan Terms:
- LTV: 75% = $2,625,000 loan
- Rate: 6.5%
- Amortization: 30 years
- Annual Debt Service: $199,200

DSCR = $245,000 / $199,200 = 1.23

✓ Meets Agency requirement (1.20-1.25)
✓ Meets Bank requirement (1.25-1.35) - borderline
✗ Does not meet CMBS (1.25-1.30) - borderline
```

## Cash-on-Cash Return Targets

### Target Returns by Strategy

```
Strategy              Year 1    Stabilized (Yr 3-5)
---------------------------------------------------
Core (low risk)       5-7%         6-8%
Core Plus            6-8%         8-10%
Value-Add            3-6%         10-15%
Opportunistic        0-5%         15-20%+
```

### Cash-on-Cash Calculation

```
Total Cash Invested:
+ Down payment (purchase price - loan amount)
+ Closing costs (1.5-3% of purchase price)
+ Immediate repairs/CapEx
+ Renovation budget
+ Working capital / reserves
+ Loan fees
= Total Cash Required

Annual Pre-Tax Cash Flow:
NOI - Annual Debt Service = Cash Flow

Cash-on-Cash = Annual Cash Flow / Total Cash Invested
```

### Example Calculation

```
Purchase Price: $2,000,000
Loan Amount (75% LTV): $1,500,000

Cash Investment:
- Down Payment: $500,000
- Closing Costs: $50,000
- Renovation Budget: $200,000
- Reserves: $30,000
= Total Cash: $780,000

Year 1 NOI: $140,000
Annual Debt Service: $115,000
Year 1 Cash Flow: $25,000

Year 1 Cash-on-Cash = $25,000 / $780,000 = 3.2%

Year 3 (Stabilized) NOI: $190,000
Year 3 Cash Flow: $75,000

Year 3 Cash-on-Cash = $75,000 / $780,000 = 9.6%
```

## IRR Modeling for Value-Add

### Target IRR Ranges

```
Hold Period    Target IRR (Value-Add)
-------------------------------------
3 years            18-25%
5 years            15-20%
7 years            13-18%
10 years           12-15%
```

### IRR Components

```
1. Annual Cash Flow (Distributions)
   - Year 1: Often low or negative during renovation
   - Years 2-3: Increasing as rents stabilize
   - Years 4-5: Steady-state distributions

2. Principal Paydown
   - Builds equity silently
   - Realized upon sale or refinance
   - Typically 2-3% of loan balance/year initially

3. Appreciation at Sale
   - Forced appreciation: NOI growth x cap rate
   - Market appreciation: Cap rate compression (or expansion)
   - Combined effect drives exit value
```

### IRR Sensitivity Drivers

```
Most Impactful (in order):
1. Exit cap rate (+/- 50 bps = +/- 3-5% IRR)
2. Rent growth assumptions (+/- 1% annually = +/- 2-3% IRR)
3. Renovation costs (+/- 20% = +/- 1-2% IRR)
4. Vacancy during renovation (+/- 30 days/unit = +/- 0.5-1% IRR)
5. Hold period (shorter often = higher IRR, lower total return)
```

### Sample IRR Waterfall

```
5-Year Value-Add Example:

Initial Investment: ($780,000)
Year 1 Cash Flow: $25,000
Year 2 Cash Flow: $50,000
Year 3 Cash Flow: $75,000
Year 4 Cash Flow: $80,000
Year 5 Cash Flow: $85,000
Year 5 Sale Proceeds: $1,200,000 (after loan payoff and costs)

IRR Calculation:
Year 0: -$780,000
Year 1: +$25,000
Year 2: +$50,000
Year 3: +$75,000
Year 4: +$80,000
Year 5: +$85,000 + $1,200,000 = $1,285,000

IRR = 17.8%

Equity Multiple = Total Distributions / Initial Investment
= ($25K + $50K + $75K + $80K + $85K + $1,200K) / $780K
= 1.94x
```

## Sensitivity Analysis Framework

### Required Scenarios

#### 1. Base Case
- Market rent growth: 2% annually
- Exit cap: Going-in + 25 bps
- Renovation costs: Budget
- Vacancy: 5% stabilized

#### 2. Downside Case
- Rent growth: 0%
- Exit cap: Going-in + 75 bps
- Renovation costs: Budget + 20%
- Vacancy: 8% stabilized
- Interest rate: +50 bps from quote

- Rent growth: 4% annually
- Exit cap: Going-in (flat)

### Decision Thresholds

```
Proceed if:
- Base Case IRR > 15%
- Downside IRR > 10%
- Downside Cash-on-Cash (Yr 3) > 6%
- DSCR never falls below 1.15 in any scenario

Reconsider if:
- Base Case IRR 12-15%
- Downside IRR 8-10%
- Significant variance between scenarios

Walk Away if:
- Base Case IRR < 12%
- Downside IRR < 8%
- DSCR falls below 1.0 in stress scenario
```

## NOI Calculation - Detailed Formulas

### Core NOI Formula

```
NOI = Gross Potential Rent (GPR)
    - Vacancy & Credit Loss
    - Concessions
    + Other Income
    - Operating Expenses
```

### Gross Potential Rent (GPR)

```
GPR = Total Units × Average Rent × 12 months
```

**Example - 200-Unit Class B Property:**
```
GPR = 200 units × $1,450/month × 12 = $3,480,000
```

## Cash-on-Cash Return - Advanced

### Cash-on-Cash Formula

```
Cash-on-Cash = Annual Pre-Tax Cash Flow / Total Cash Invested

Annual Pre-Tax Cash Flow = NOI - Debt Service
Total Cash Invested = Down Payment + Closing Costs + CapEx Reserves
```

### Target Returns by Strategy (DFW 2025)

| Strategy | Target CoC Year 1 | Stabilized CoC | Risk Profile |
|----------|-------------------|----------------|--------------|
| Core | 4-6% | 5-7% | Low - predictable |
| Core Plus | 5-8% | 7-10% | Low-Medium |
| Value-Add | 2-6% | 8-12% | Medium-High |
| Opportunistic | Negative-3% | 12-18% | High |

## Quick Reference Formulas

### Core Calculations

```
GPR = Units × Avg Rent × 12
EGI = GPR × (1 - Vacancy) + Other Income
NOI = EGI - Operating Expenses
Cap Rate = NOI / Value
Value = NOI / Cap Rate
DSCR = NOI / Annual Debt Service
CoC = (NOI - Debt Service) / Cash Invested
Debt Yield = NOI / Loan Amount
```
