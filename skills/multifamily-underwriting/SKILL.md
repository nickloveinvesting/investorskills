# Multifamily Underwriting Skill

Expert guidance for underwriting 5-50 unit multifamily properties, with specialization in pre-1990s buildings and value-add investment strategies in the DFW Texas market.

---

## Overview

This skill provides a systematic methodology for evaluating multifamily investment opportunities, focusing on:

- **Target Property Profile**: 5-50 unit buildings, primarily pre-1990s construction
- **Asset Classes**: Class B and C workforce housing
- **Investment Strategy**: Value-add acquisitions with rent growth and expense optimization
- **Geographic Focus**: Dallas-Fort Worth metroplex with applicable nationwide principles

### When to Use This Skill

Use this skill when you need to:
- Analyze an apartment deal's financial viability
- Calculate NOI, cap rate, DSCR, IRR, or cash-on-cash returns
- Evaluate renovation budgets and value-add potential
- Assess building systems in older properties
- Create due diligence checklists for acquisitions
- Determine appropriate offer pricing
- Structure creative financing (seller financing, assumptions)

## Quick Reference: Key Financial Metrics

### Income Metrics

| Metric | Formula | Purpose |
|--------|---------|---------|
| Gross Potential Rent (GPR) | Units x Market Rent x 12 | Maximum possible rental income |
| Vacancy Loss | GPR x Vacancy Rate | Expected income loss from vacancies |
| Effective Gross Income (EGI) | GPR - Vacancy - Concessions + Other Income | Actual expected income |
| Net Operating Income (NOI) | EGI - Operating Expenses | Income before debt service |

### Return Metrics

| Metric | Formula | Target Range |
|--------|---------|--------------|
| Cap Rate | NOI / Purchase Price | 5.5-7.0% (DFW Class B/C) |
| Cash-on-Cash | Annual Cash Flow / Total Cash Invested | 8%+ stabilized |
| DSCR | NOI / Annual Debt Service | 1.25x minimum |
| Equity Multiple | Total Distributions / Total Equity | 2.0x+ over 5-year hold |
| IRR | Internal Rate of Return | 15%+ levered |

### Expense Benchmarks (Per Unit/Year - DFW Market)

| Category | Class B Range | Class C Range |
|----------|---------------|---------------|
| Property Taxes | $1,800-2,500 | $1,200-1,800 |
| Insurance | $800-1,200 | $1,000-1,500 |
| Utilities (owner-paid) | $600-1,000 | $800-1,400 |
| Repairs & Maintenance | $800-1,200 | $1,200-2,000 |
| Property Management | 6-8% of EGI | 7-10% of EGI |
| CapEx Reserves | $300-500 | $400-600 |
| **Total Operating Expense Ratio** | **40-50%** | **45-55%** |

## Step-by-Step Underwriting Workflow

### Phase 1: Initial Screening (30 minutes)

**Quick Kill Criteria** - Reject if ANY apply:
- Price per unit > 150% of market average for submarket
- Occupancy < 80% without clear turnaround path
- Structural issues visible from exterior (foundation cracks, roof sag)
- Environmental contamination history
- Flood zone AE or V without existing flood insurance
- Ownership disputes or title clouds
- Active litigation involving property

**Initial Metrics to Calculate:**
```
Price Per Unit = Purchase Price / Unit Count
Price Per SF = Purchase Price / Total Rentable SF
In-Place Cap Rate = Current NOI / Purchase Price
Gross Rent Multiplier = Purchase Price / Annual Gross Rent
```

**Data to Request from Seller:**
- [ ] Trailing 12-month P&L (T12) - month by month
- [ ] Current rent roll with lease expiration dates
- [ ] Utility bills (12 months minimum)
- [ ] Property tax statements (2-3 years)
- [ ] Insurance declarations page
- [ ] Unit mix and floor plans
- [ ] Recent CapEx history and invoices

### Phase 2: Financial Deep Dive (4-8 hours)

**T12 Normalization Checklist:**
- [ ] Remove one-time income items (late fees spikes, insurance claims)
- [ ] Annualize partial-year expenses
- [ ] Add back owner-managed expenses (if self-managed, add 8% management fee)
- [ ] Adjust vacancy to market rate (8-10% for DFW 2024-2025)
- [ ] Verify property tax reflects current assessment
- [ ] Obtain insurance quote for your intended coverage

**Rent Roll Analysis:**
- [ ] Compare in-place rents to market comps (pull 3-5 comps within 1 mile)
- [ ] Calculate loss-to-lease: (Market Rent - In-Place Rent) x 12
- [ ] Identify month-to-month tenants (opportunity for immediate increases)
- [ ] Note lease expiration clustering (renovation timing)
- [ ] Flag below-market long-term tenants
- [ ] Calculate effective rent after concessions

**Income Reconstruction:**
```
Gross Potential Rent (GPR)
  - Vacancy Loss (8-10% for DFW 2024-2025)
  - Concessions (1-2 months free if offering)
  + Other Income (laundry, parking, RUBS, pet fees, late fees)
= Effective Gross Income (EGI)
```

**Expense Validation:**
- Compare each line item to benchmarks above
- Flag any category below typical range (likely understated)
- Add reserves for CapEx ($300-500/unit/year)
- Calculate realistic expense ratio

### Phase 3: Physical Due Diligence (1-2 days on-site)

**Building Systems Assessment (Pre-1990s Priority):**
- [ ] **Plumbing**: Main lines, supply type (galvanized = near-term replacement)
- [ ] **Electrical**: Panel capacity, aluminum wiring check, GFI in wet areas
- [ ] **HVAC**: Age, type, R-22 equipment requiring replacement
- [ ] **Roof**: Age, material, drainage, signs of ponding
- [ ] **Foundation**: Cracks, settling, drainage grading
- [ ] **Windows**: Single-pane, seal failures, operability
- [ ] **Exterior**: Siding condition, paint, wood rot

**Pre-1978 Specific Items:**
- [ ] Lead-based paint disclosure review
- [ ] Asbestos survey (popcorn ceilings, floor tiles, pipe insulation)
- [ ] Window glazing assessment

**Unit Walk Requirements:**
- Sample minimum 20-30% of units
- Walk ALL vacant units
- Document deferred maintenance with photos
- Estimate unit turn costs

See [Pre-1990 Due Diligence](./references/pre1990-due-diligence.md) for complete checklists.

### Phase 4: Value-Add Business Plan (2-4 hours)

**Renovation Scope Definition:**

| Level | Per-Unit Cost | Rent Premium | Scope |
|-------|---------------|--------------|-------|
| Light | $3,000-5,000 | $75-125/mo | Paint, hardware, fixtures, cleaning |
| Medium | $8,000-12,000 | $150-250/mo | + Flooring, appliances, countertops |
| Heavy | $15,000-25,000 | $250-400/mo | + Cabinets, bathrooms, full rehab |

**ROI Target**: $1 rent increase per $100-150 renovation spend

**Timeline Considerations:**
- Unit turns during natural turnover (6-12 month rollout)
- Exterior/common area improvements Year 1
- RUBS implementation within 90 days
- Rent increases at lease renewal

See [Rehab Estimation](./references/rehab-estimation.md) and [Value-Add Playbook](./references/value-add-playbook.md).

### Phase 5: Final Underwriting (2-4 hours)

**Pro Forma Construction:**
```
Year 1: Conservative (current occupancy, minimal rent growth)
Year 2-3: Value-add execution (renovations complete, rent increases)
Year 4-5: Stabilized operations (market growth, normalized expenses)
Exit: Apply exit cap rate (+50-75 bps from entry)
```

**Financing Analysis:**
- Obtain term sheet quotes (bank, agency, bridge)
- Calculate DSCR at various interest rates
- Stress test with 100-200 bps rate increase
- Model refinance at Year 3 if using bridge debt

**Sensitivity Analysis Must-Haves:**
- Exit cap rate: +/- 50 basis points
- Rent growth: Base case, +2%, -2%
- Renovation costs: +15% overrun scenario
- Vacancy: +200 bps from assumption

**Investment Decision Metrics:**
```
Target Purchase Price = Stabilized NOI / Target Cap Rate - Renovation Costs - Closing Costs
```

See [Financial Models](./references/financial-models.md) for complete templates.

## DFW Texas Market Context (2024-2025)

### Current Market Conditions

| Factor | Current Status | Implication |
|--------|----------------|-------------|
| Vacancy Rate | 8-12% (submarket dependent) | Use 8-10% in underwriting |
| Rent Growth | Flat to -2% YoY | Conservative Year 1 assumptions |
| New Supply | Record deliveries 2023-2024, declining 2025+ | Pressure easing |
| Cap Rates | 5.5-7.0% Class B/C | Buyer's market emerging |
| Interest Rates | 6.5-7.5% conventional | DSCR compression, watch debt coverage |
| Insurance | +15-20% annual increases | Budget conservatively |
| Property Taxes | +8-10% annual increases | Verify current assessment |

### Submarket Guidance

**Stronger Submarkets (Lower Risk)**
- Garland, Richardson, Plano (established employment)
- Arlington (central locations near employers)
- Irving (Las Colinas adjacent)
- Target Cap Rate: 5.5-6.5%

**Value-Add Submarkets (Higher Risk/Reward)**
- South Dallas / Pleasant Grove
- East Fort Worth
- Mesquite
- Lancaster / DeSoto
- Target Cap Rate: 6.5-7.5%

### Underwriting Adjustments for Current Market

1. **Vacancy**: 8-10% economic vacancy minimum
2. **Rent Growth**: Year 1: 0%, Years 2-3: 2-3%, Years 4-5: 3-4%
3. **Concessions**: Budget 1-2 months free in Year 1 if needed
4. **Exit Cap**: Add 50-75 bps to entry cap for conservative exit
5. **Insurance**: Budget 15-20% annual increases
6. **Property Taxes**: Budget 8-10% annual increases

## Go/No-Go Decision Framework

### GREEN FLAGS - Proceed with Confidence
- In-place cap rate > 6% with value-add upside
- Loss-to-lease > 15% (significant rent increase opportunity)
- Occupancy > 90% with stable tenant base
- Deferred maintenance is cosmetic, not structural
- Clear path to 1.25+ DSCR post-stabilization
- Submarket with job growth and limited new supply
- Seller-provided financials verified by documentation

### YELLOW FLAGS - Proceed with Caution / Price Adjustment
- Occupancy 80-90% (budget lease-up costs)
- Single major system near end-of-life (roof, HVAC, plumbing)
- Below-market tenant concentration > 30%
- Trailing NOI declining (investigate root cause)
- High turnover rate > 50% annually
- Deferred maintenance 10-20% of purchase price
- Environmental Phase I recommends Phase II
- Master-metered utilities (budget RUBS implementation)
- High Section 8 concentration > 40%

### RED FLAGS - Walk Away or Significant Discount
- Structural issues requiring engineering (foundation, framing)
- Environmental contamination confirmed
- Title issues unresolved
- DSCR < 1.0 with no clear path to positive coverage
- Major code violations (fire, life safety)
- Ownership/legal disputes
- Fraud indicators in financials (inconsistent records)
- Foundation issues in expansive clay soils
- Full galvanized pipe replacement needed
- Aluminum branch wiring throughout building
- Federal Pacific or Zinsco electrical panels

## Essential Formulas Quick Reference

### Net Operating Income (NOI)
```
Gross Potential Rent (GPR)
- Vacancy Loss (8-10%)
- Concessions
+ Other Income (laundry, parking, RUBS, fees)
= Effective Gross Income (EGI)

- Property Taxes
- Insurance
- Utilities (owner-paid)
- Repairs & Maintenance
- Property Management
- Administrative
- Contract Services
- CapEx Reserves ($300-500/unit)
= Net Operating Income (NOI)
```

### Cap Rate & Value
```
Cap Rate = NOI / Purchase Price
Value = NOI / Target Cap Rate

Example:
$150,000 NOI / $2,500,000 Price = 6.0% Cap Rate
$150,000 NOI / 0.065 Target Cap = $2,307,692 Value
```

### Debt Service Coverage Ratio
```
DSCR = NOI / Annual Debt Service

Lender Requirements:
- Agency (Fannie/Freddie): 1.20 - 1.25
- CMBS: 1.25 - 1.30
- Bridge: 1.10 - 1.15
- Local Bank: 1.25 - 1.35

Example:
$150,000 NOI / $115,000 Annual Debt Service = 1.30x DSCR
```

### Cash-on-Cash Return
```
Cash-on-Cash = Annual Pre-Tax Cash Flow / Total Cash Invested

Total Cash Invested = Down Payment + Closing Costs + Renovation Budget + Reserves

Example:
$35,000 Annual Cash Flow / $500,000 Total Cash = 7.0% Cash-on-Cash
```

### IRR Calculation Components
```
IRR considers:
- Initial equity investment (negative)
- Annual cash flows (Years 1-5)
- Sale proceeds at exit (Year 5)

Target IRR: 15-20% for value-add deals
```

## Quick Checklists

### Before Making an Offer
- [ ] T12 reviewed and normalized
- [ ] Rent roll analyzed with market comp comparison
- [ ] Physical inspection completed (or walk scheduled)
- [ ] Pro forma built with 5-year projections
- [ ] DSCR calculated for target loan terms
- [ ] Sensitivity analysis completed
- [ ] Exit strategy defined
- [ ] Renovation budget estimated

### Due Diligence Period (30-45 days)

**Week 1:**
- [ ] Phase I Environmental ordered
- [ ] Property Condition Assessment ordered
- [ ] ALTA Survey ordered
- [ ] Appraisal ordered (if lender financing)
- [ ] Zoning verification requested

**Week 2-3:**
- [ ] All leases reviewed (verify terms match rent roll)
- [ ] Service contracts reviewed (transferability, termination)
- [ ] Warranties collected (roof, HVAC, appliances)
- [ ] Historical CapEx documentation reviewed
- [ ] Utility accounts transfer requirements confirmed
- [ ] Permits for recent work verified

**Week 4:**
- [ ] All units walked (vacant = 100%, occupied = sample)
- [ ] Tenant estoppels collected
- [ ] Final title commitment reviewed
- [ ] Insurance binder in place
- [ ] Property management transition planned
- [ ] Renovation contractor bids finalized
- [ ] Financing docs reviewed and approved

## Usage Tips

1. **Start with the T12**: Always begin analysis with actual trailing financials, not broker proforma
2. **Verify Everything**: Seller-provided numbers are starting points, not facts
3. **Walk the Property**: Never underwrite without physical inspection
4. **Know Your Market**: Build your own comp database - comps are king
5. **Model Conservatively**: Assume things cost more and take longer than planned
6. **Have an Exit**: Know your refinance and sale scenarios before buying
7. **Size Your Reserves**: Maintain 6+ months of debt service in reserves
