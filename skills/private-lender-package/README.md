Assemble the loan package that gets a private lender to yes without a second round of document requests.

- **Price:** $27
- **Built for:** Fix-and-Flipper, Small Multifamily Investor

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/private-lender-package/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.
