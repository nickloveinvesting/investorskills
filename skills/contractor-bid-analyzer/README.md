# Contractor Bid Analyzer

Compare three bids that are structured three different ways and find what each one quietly left out.

- **Category:** Rehab Scoping & Contractors
- **Price:** Free
- **Built for:** Fix-and-Flipper

## Install

**Claude Projects** - add `SKILL.md` to project knowledge.
**Claude Code** - copy the folder into `.claude/skills/contractor-bid-analyzer/`.
**ChatGPT** - paste `SKILL.md` into a Project's instructions.
**Cursor** - append `SKILL.md` to `.cursorrules`.

Full guide: [`docs/installation.md`](../../docs/installation.md)
